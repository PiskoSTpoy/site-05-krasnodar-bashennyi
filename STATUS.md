## kran-kuban.ru — этап 1 (шелл/шаблон), 25.09.2026

**Контекст:** Astro, статическая сборка (`astro build` → `dist/`). `grep -rl "client:load\|client:idle\|client:visible\|client:only"` по `src/` не нашёл ни одного острова — весь интерактив на сайте (reading-progress, ToC-highlight) собран обычными `<script>` без клиентской гидратации фреймворка. Значит класса регрессии «hydration mismatch» (пойманного на manipmo.ru и kranneva.ru) здесь в принципе не существует — но живая проверка консоли всё равно обязательна, не как формальность, а как подтверждение этого вывода для конкретного сайта, а не как допущение по аналогии (именно на допущении по аналогии споткнулась kranneva.ru).

**Важная находка ДО патча:** у блога (32 статьи) уже полная обвязка — `BlogArticleLayout.astro`: id на H2 проставляются вручную в каждой статье через `lib/slug.ts` slugify (массив `H2`/`headings` в front-matter каждого файла), TOC desktop-sticky + mobile-`<details>` рендерится Astro-компонентом на сервере, byline «Инженерная служба КРАН-КУБАНЬ», related-posts, `Sources.astro`. Остальные ~24 страницы (park/etapy/seysmozony/documents/kontakty/faq/index/partnerskaya-set/политики) используют `BaseLayout` напрямую — там нет вообще ничего из этого.

**Baseline:** 57 стр., 51 FAIL, 6 WARN, 0 PASS (FAIL — в основном контентные: intro на стоп-фразу «В этой статье…» на большинстве старых статей блога, не шаблонное). Топ WARN: H2 без id (55, из них 32 блог-страницы — только 1 H2 без id на каждой, остальные — не-блоговые страницы целиком), нет TOC при N H2 (23), нет источников (56), нет `<time>` (56).

**Сделано:** `scripts/geo2026-postbuild.mjs`, подключён в `package.json` → `build` (после `astro build && sitemap-lastmod.mjs`). Проходит по `dist/**/*.html`, в рамках `<main>`:
- добавляет `id` на каждый `<h2>` без id — тот же Cyrillic-safe slugify, что уже в `lib/slug.ts` (сохранена консистентность с уже принятой на сайте практикой, не транслит, как на kran365/moskran-servis/kranneva);
- если на странице ≥3 H2 и своей обвязки TOC нет (проверка на `class="toc-desktop"`/`"toc-mobile"`/`"g26-toc"` — чтобы не задвоить блог) — вставляет самодостаточный `<nav class="g26-toc">` со своим инлайновым `<style>` (не переиспользует `.toc-desktop` блога: та вёрстка объявлена `is:global` внутри `BlogArticleLayout.astro` и бандлится Astro только туда, где этот layout импортирован, — на park/etapy её в бандле нет).

После патча: 70 файлов обработано, 55 изменено. «H2 без id» и «нет оглавления (TOC)» полностью пропали из топ-10.
